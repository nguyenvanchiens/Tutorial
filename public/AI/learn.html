AI Landscape — Buc tranh toan canh
Hieu dung truoc khi lam — dung hoc lung tung

AI khong phai 1 thu — no la 1 he sinh thai

Nhieu nguoi nghe "hoc AI" la nhay vao hoc neural network, gradient descent. SAI. Nhu developer, ban can hieu AI tu goc do THUC CHIEN:

  • AI-as-a-Service (dung API) — Goi API cua OpenAI, Anthropic, Google de tich hop AI vao app. Day la 80% cong viec AI cua developer.
  • AI Engineering (xay pipeline) — RAG, AI agents, function calling, embeddings. Gop nhieu manh ghep AI thanh he thong hoan chinh.
  • ML Engineering (train model) — Fine-tune model, train tu dau. Chi can khi ban co USE CASE CU THE, khong phai de "hoc cho biet".
  • ML Research (nghien cuu) — Tao model moi, viet paper. KHONG phai muc tieu cua developer — de cho researcher.
Quy tac vang: Developer nen bat dau tu tang 1 (API) → tang 2 (Engineering) → chi xuong tang 3 (Training) khi THAT SU can. 90% gia tri kinh doanh nam o tang 1 va 2.

03
Prompt Engineering
Ky nang quan trong nhat cua AI developer. Prompt tot = output tot.

Module 3.1: Nguyen tac viet Prompt

Beginner

Prompt khong phai "hoi cho dung". Prompt la PROGRAMMING — ban dang "lap trinh" cach model suy nghi.

5 nguyen tac core:
  • Be Specific: "Viet API endpoint" → "Viet POST /api/users bang ASP.NET Core 8, validate email, return 201 voi user ID"
  • Give Context: Cho model biet ban la ai, project gi, constraint gi. Model khong doan duoc context cua ban.
  • Show Examples (Few-shot): Cho 2-3 vi du input → output. Model se hieu pattern va lam theo.
  • Think Step by Step: Yeu cau model suy nghi tung buoc truoc khi tra loi. Tang chat luong dang ke voi task phuc tap.
  • Define Output Format: Yeu cau tra ve JSON, Markdown, hoac format cu the. Giup parse output de dang.

Module 3.2: System Prompt & Persona

Intermediate

System prompt la "luat choi" cho model. Giong nhu ban viet spec cho 1 nhan vien moi — cang ro rang, ket qua cang tot.

Module 3.3: Advanced Techniques

Advanced

Nhung ky thuat nay tach biet giua nguoi "dung AI" va nguoi "lam chu AI":

  • Chain-of-Thought (CoT): Bat model "suy nghi to" — tang do chinh xac voi math, logic, code
  • Self-Consistency: Chay cung prompt nhieu lan, lay ket qua pho bien nhat
  • ReAct Pattern: Model suy nghi (Reason) → hanh dong (Act) → quan sat ket qua → lap lai. Nen tang cua AI Agents.
  • Prompt Chaining: Tach 1 task lon thanh nhieu prompt nho, output cua prompt truoc la input cua prompt sau
  • Structured Output: Bat model tra ve JSON schema cu the — dung cho API integration

04
RAG — Retrieval Augmented Generation
Cho AI doc tai lieu cua BAN. Ky thuat duoc dung nhieu nhat trong enterprise.

RAG la gi va tai sao quan trong?

LLM biet nhieu nhung KHONG biet du lieu cua ban — noi quy cong ty, tai lieu ky thuat, database san pham. RAG = cho model "doc bai" truoc khi tra loi.

Pipeline RAG don gian: Tai lieu → Tach chunk → Tao embedding → Luu vector DB → User hoi → Tim chunk lien quan → Gui chunk + cau hoi cho LLM → Tra loi co nguon

Module 4.1: Xay RAG Pipeline

Intermediate

Pipeline co ban: Document Loading → Chunking → Embedding → Vector Store → Retrieval → Generation

Ban se build: Chatbot doc duoc PDF noi quy cong ty, tra loi cau hoi dua tren tai lieu noi bo
# Python — RAG voi LangChain (don gian nhat) from langchain.document_loaders import PyPDFLoader from langchain.text_splitter import RecursiveCharacterTextSplitter from langchain.embeddings import OpenAIEmbeddings from langchain.vectorstores import Chroma from langchain.chat_models import ChatOpenAI from langchain.chains import RetrievalQA # 1. Load tai lieu docs = PyPDFLoader("company-policy.pdf").load() # 2. Tach thanh chunks nho chunks = RecursiveCharacterTextSplitter(chunk_size=500).split_documents(docs) # 3. Tao vector store vectorstore = Chroma.from_documents(chunks, OpenAIEmbeddings()) # 4. Tao chain: hoi → tim tai lieu → tra loi qa = RetrievalQA.from_chain_type( llm=ChatOpenAI(model="gpt-4o"), retriever=vectorstore.as_retriever() ) # 5. Hoi answer = qa.run("Chinh sach nghi phep cong ty nhu the nao?")

Module 4.2: RAG nang cao

Advanced

RAG co ban se gap van de: tra sai tai lieu, chunk qua nho/lon, khong hieu context. Day la cach fix:

  • Hybrid Search: Ket hop vector search + keyword search (BM25) — tang do chinh xac
  • Reranking: Sau khi tim duoc 20 chunk, dung model nho de xep hang lai → lay top 5 chinh xac nhat
  • Contextual Chunking: Chunk thong minh hon — giu nguyen cau, paragraph, table. Khong cat giua cau.
  • Query Expansion: Mo rong cau hoi user de tim duoc nhieu ket qua hon
  • Citation: Tra loi kem link den doan tai lieu goc — de user verify

Vector Database & Embeddings
Ha tang nen tang cho RAG va semantic search

Embedding la gi?

Embedding = chuyen text thanh mang so (vector). Text giong nghia → vector gan nhau. Day la cach may tinh "hieu" nghia cua text.

"Con meo" → [0.2, 0.8, 0.1, ...] va "Cat" → [0.21, 0.79, 0.12, ...] se rat GAN nhau trong khong gian vector.

Deploy AI len Production
Tu prototype den production — nhung bai hoc dat gia

Checklist truoc khi deploy AI

  • Rate Limiting: Gioi han so request/user/phut — tranh user spam → bill khung
  • Content Filtering: Loc input/output — tranh model noi nhung dieu khong nen noi
  • Fallback Strategy: Khi model A chet → tu dong chuyen sang model B
  • Logging & Monitoring: Log moi request/response — de debug, danh gia chat luong, tinh cost
  • Caching: Cache response cho cau hoi giong nhau — giam cost 50-80%
  • Timeout: Set timeout 30s — LLM co the mat 10-60s, user khong cho lau hon
  • Cost Alerts: Set alert khi chi phi vuot nguong — tranh "bill shock"
  • User Feedback Loop: Thu thap phan hoi tu user — de cai thien prompt/RAG theo thoi gian

Module 8.1: Architecture Patterns

Advanced
Cac pattern pho bien:
  • API Gateway + LLM: API nhan request → validate → goi LLM → cache → tra ve. Don gian nhat.
  • Queue-based: Request vao queue → worker xu ly → webhook/polling ket qua. Cho task nang (tong hop tai lieu dai).
  • Streaming SSE: API stream response ve client real-time. UX tot nhat cho chat.
  • Agent Loop: Request → Agent plan → Tool calls → Observe → Repeat → Final response. Cho task phuc tap.
