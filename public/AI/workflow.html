PROMPT LÀM VIỆC

Quy trình làm việc với AI

6 bước chuẩn để code AI viết ra luôn sạch trước khi merge: review nhiều lớp, làm sạch context giữa các lớp, rồi mới tạo và chốt MR. Mỗi bước kèm sẵn prompt/lệnh để copy dùng.

6 Bước

01 Review cục bộ (trong lúc làm) 02 Review tổng thể (toàn branch) 03 Sửa & review lại 04 Tạo MR 05 Review lại trên MR 06 Sửa theo feedback & cập nhật MR
Nguyên tắc xuyên suốt: review nhiều lớp + /clear để làm sạch context giữa các lớp. Mỗi lần review nên có "đầu óc tỉnh táo" — context cũ lẫn lộn sẽ làm AI review qua loa hoặc review nhầm theo code đã bị bỏ.
01
Review trong lúc làm (review cục bộ)
Bắt lỗi sớm ngay khi đang code

Làm gì

Đang code
  • Review thủ công 1–2 file cụ thể đang sửa, hoặc
  • Dùng /simplify để review nhanh các file đã thay đổi nhưng chưa commit (đây là phiên bản giới hạn của review-branch).
/simplify
/simplifyReview cục bộ

Review tổng thể
Khi code đã ổn — quét cả branch

Làm gì

Code đã ổn

Khi thấy code đã ổn, chạy review-branch để kiểm tra toàn bộ branch — không chỉ vài file lẻ.

review-branch
review-branch
03
Sửa & review lại (nếu sửa nhiều)
Làm sạch context rồi soi lại

Làm gì

Sửa nhiều

Sau khi sửa xong, nếu thay đổi nhiều → chạy /clear để xoá context cũ → chạy lại review một lần nữa cho sạch.

/clear review-branch
Vì sao /clear? Context cũ chứa code đã bị sửa/loại bỏ — để nguyên thì AI dễ review nhầm theo phiên bản cũ.
/clearReview lại

Review pass

Trên MR

Sửa theo feedback & cập nhật MR

Làm gì

Khép vòng

Bảo AI sửa theo feedback → commit → push để update MR luôn.

Sửa theo các feedback ở trên, sau đó commit và push để cập nhật MR.
FixCommit & PushUpdate MR
Tóm tắt vòng lặp: /simplify (cục bộ) → review-branch (toàn branch) → /clear + review lại → tạo MR → /clear + review the MR !id → sửa & push. Mỗi lớp một góc nhìn sạch, code merge ra luôn yên tâm.
