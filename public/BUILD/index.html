🏗️ Các Môi Trường (Environments)

Website không bao giờ deploy thẳng từ máy bạn lên production. Luôn có nhiều tầng.

Local (Dev)
Máy của bạn. Code, debug, test tại đây. Thoải mái phá.
VS Code, localhost:3000, hot reload
→
Development
Server chung cho team dev. Integrate code từ nhiều người.
dev.myapp.com, shared DB, feature flags
→
Staging
Bản sao y hệt production. QA test ở đây trước khi go live.
staging.myapp.com, prod-like data, UAT
→
Production
User thật truy cập. Không được sai. Mọi thay đổi phải cẩn thận.
myapp.com, real data, monitoring 24/7
⚠️ Quy tắc vàng: KHÔNG BAO GIỜ test trên production. KHÔNG BAO GIỜ deploy trực tiếp lên production mà không qua staging. "Chỉ fix nhỏ thôi" = câu nói trước mọi sự cố.

📊 Frontend vs Backend — Deploy khác nhau

🎨 Frontend (React, Vue, Angular, Next.js)

Build output: HTML, CSS, JS tĩnh (static files)
Deploy đơn giản: Upload static files lên CDN
Hosting phổ biến: Vercel, Netlify, Cloudflare Pages, GitHub Pages
SSR/SSG: Next.js, Nuxt → cần server hoặc serverless
Thời gian deploy: 30 giây — 2 phút

⚙️ Backend (.NET, Node.js, Go, Python)

Build output: Binary/runtime cần server chạy liên tục
Deploy phức tạp hơn: Cần server, database, environment config
Hosting phổ biến: Azure, AWS, Railway, Render, VPS
Docker: Gần như bắt buộc cho backend production
Thời gian deploy: 2 — 10 phút (build + test + deploy)
