🎨 Frontend Hosting — Static Sites & SSR

⭐ TUYỆT VỜI CHO FE

Vercel

Free → $20/tháng
✅ Deploy Next.js tốt nhất (họ tạo ra Next.js)
✅ Push code → auto deploy trong 30 giây
✅ Preview URL cho mỗi PR
✅ Edge Functions, CDN toàn cầu
✅ Free SSL, custom domain
Deploy: git push hoặc vercel deploy
⭐ TUYỆT VỜI CHO FE

Netlify

Free → $19/tháng
✅ Static sites, React, Vue, Angular
✅ Form handling, serverless functions
✅ Split testing (A/B), branch deploys
✅ CDN, free SSL, instant rollback
Deploy: Drag & drop folder hoặc git push
🟢 ĐANG DÙNG - FREE

Cloudflare Pages

Free (rất hào phóng)
✅ Unlimited bandwidth miễn phí
✅ CDN nhanh nhất thế giới (Cloudflare network)
✅ Workers cho server-side logic
✅ Tích hợp Cloudflare DNS, DDoS protection
✅ 500 builds/tháng, unlimited sites
✅ Auto deploy từ GitHub/GitLab
Deploy: Git integration hoặc wrangler pages deploy

GitHub Pages

Free
✅ Hoàn toàn miễn phí cho public repo
✅ Static sites, Jekyll, Hugo
⚠️ Không hỗ trợ SSR, server-side
⚠️ Chỉ static HTML/CSS/JS
Deploy: Push vào branch gh-pages hoặc GitHub Actions

⚙️ Backend Hosting — Server & PaaS

⭐ DỄ NHẤT CHO .NET

Azure App Service

Free tier → $13/tháng (Basic)
✅ Deploy .NET nhanh nhất — tích hợp Visual Studio
✅ Auto-scaling, deployment slots
✅ Managed SSL, custom domain
✅ Azure SQL, Blob Storage tích hợp
Deploy: az webapp up hoặc GitHub Actions → Azure
⭐ SIMPLE & MODERN

Railway

$5/tháng (usage-based)
✅ Push code → auto detect & deploy (mọi ngôn ngữ)
✅ Database (PostgreSQL, MySQL, Redis) tích hợp
✅ Environment variables UI đẹp
✅ Preview environments cho PR
Deploy: git push hoặc railway up

Render

Free → $7/tháng
✅ "Heroku thế hệ mới" — dễ dùng
✅ Docker support, auto deploy từ Git
✅ Free PostgreSQL (90 ngày), managed Redis
⚠️ Free tier sleep sau 15 phút không dùng
Deploy: Connect GitHub repo → auto deploy
🟢 ĐANG DÙNG - FREE

MonsterASP.net

Free (Windows Hosting)
✅ Hỗ trợ ASP.NET / .NET Core miễn phí
✅ MSSQL Server database đi kèm
✅ Windows IIS hosting — phù hợp .NET dev
✅ Control panel quản lý dễ dùng
⚠️ Giới hạn disk space & bandwidth ở plan free
⚠️ Phù hợp cho học tập, demo, project nhỏ
Deploy: FTP upload hoặc Web Deploy từ Visual Studio

$4-$12/tháng
✅ Toàn quyền kiểm soát server
