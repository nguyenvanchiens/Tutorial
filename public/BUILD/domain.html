7. Domain & DNS — Từ IP Đến Tên Miền

Không ai nhớ 104.21.34.56 — nhưng ai cũng nhớ google.com. DNS chính là "danh bạ" internet.

📖 DNS Hoạt Động Thế Nào?

1
User gõ myapp.com

Browser hỏi: "IP của myapp.com là gì?"

2
DNS Resolver tìm kiếm

Hỏi lần lượt: Cache → Root DNS → .com DNS → Authoritative DNS

3
Trả về IP: 104.21.34.56

Browser biết server nào cần connect đến

4
Browser connect tới server

Gửi HTTP request đến IP, nhận response → hiển thị website

📋 DNS Records — Các Loại Quan Trọng

A
Domain → IPv4

myapp.com → 104.21.34.56 — Record cơ bản nhất, trỏ domain đến IP server.

CNAME
Domain → Domain khác

www.myapp.com → myapp.com — Alias, trỏ subdomain đến domain chính. Dùng nhiều cho Vercel, Netlify.

NS
Nameserver

Chỉ định DNS server quản lý domain. VD: chuyển sang Cloudflare DNS.

MX
Mail server

Email @myapp.com gửi đến server nào. Cần khi dùng Google Workspace, Zoho.

TXT
Text record

Xác minh domain ownership (Google, Let's Encrypt), SPF/DKIM cho email.

🛒 Mua Domain Ở Đâu?

⭐ KHUYÊN DÙNG

Cloudflare Registrar

Giá gốc (at cost), không markup. DNS nhanh nhất. Free DDoS protection, CDN.

⭐ KHUYÊN DÙNG

Namecheap

Giá tốt, UI dễ dùng, privacy protection miễn phí. Phổ biến nhất cho developer.

Google Domains → Squarespace

Đã chuyển sang Squarespace. Giá hợp lý, tích hợp Google Workspace.

Tenten.vn / PA Vietnam

Domain .vn, .com.vn. Cần cho doanh nghiệp Việt Nam, thanh toán nội địa.

⚠️ TRÁNH GoDaddy — giá rẻ năm đầu nhưng renew cắt cổ. Upsell liên tục. Developer hầu hết chuyển sang Cloudflare/Namecheap.
