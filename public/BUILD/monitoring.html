9. Monitoring & Logging — Biết Trước Khi User Báo

Deploy xong mà không monitor = lái xe bịt mắt. Bạn không biết app sống hay chết.

📈 3 Trụ Cột Monitoring (Observability)

📝

Logs

"Chuyện gì đã xảy ra?"

Ghi lại events: request, error, warning. Structured logging (JSON) cho dễ search.

Tools: Seq, ELK Stack, Azure Log Analytics, Datadog Logs
📊

Metrics

"Hệ thống đang hoạt động thế nào?"

Số liệu: response time, error rate, CPU/RAM, request count, active users.

Tools: Prometheus + Grafana, Azure Monitor, Datadog, New Relic
🔗

Traces

"Request đi qua đâu, chậm ở đâu?"

Theo dõi 1 request từ browser → API → DB → response. Tìm bottleneck.

Tools: OpenTelemetry, Jaeger, Azure Application Insights

🛠️ Monitoring Stack Khuyên Dùng

⭐ CHO .NET

Application Insights (Azure)

Tích hợp .NET chỉ 3 dòng code. Auto collect: requests, exceptions, dependencies, performance. Free tier tốt.

⭐ UPTIME

UptimeRobot / Better Uptime

Ping website mỗi 5 phút. Down → alert qua email/Slack/SMS. Free tier đủ dùng.

Sentry

Error tracking #1. Bắt mọi exception frontend + backend. Source maps, user context, breadcrumbs. Free tier hào phóng.

Grafana + Prometheus

Open source, self-hosted. Dashboard đẹp, alert mạnh. Chuẩn industry cho metrics.

🚨 Alert Rules — Cảnh Báo Gì?

🔴 P1 — Website down

Health check fail > 2 phút → gọi điện + SMS ngay

🔴 P1 — Error rate > 5%

Quá nhiều 5xx errors → có vấn đề nghiêm trọng

🟡 P2 — Response time > 3 giây

App chậm, user sẽ bỏ đi. Check DB, external APIs.

🟡 P2 — CPU/RAM > 80%

Sắp hết resource. Scale up hoặc optimize.

🔵 P3 — Disk > 85%

Log files, temp files đầy disk → app crash khi không ghi được.

🔵 P3 — SSL expiring < 14 ngày

SSL hết hạn = "Not Secure" warning. Auto-renew nên catch trước.
