Push code → tự động build, test, deploy. Không cần SSH vào server chạy tay.

📖 CI vs CD — Hiểu Đúng Khái Niệm

CI — Continuous Integration

"Mỗi khi push code → tự động build + chạy test"

Push code / Tạo PR
Restore dependencies
Build project
Chạy unit tests
Chạy integration tests
Code quality check (lint, format)
✅ hoặc ❌ → báo kết quả
Mục đích: Phát hiện lỗi NGAY khi push — không phải khi deploy

CD — Continuous Deployment / Delivery

"CI pass → tự động deploy lên staging/production"

CI pass ✅
Build Docker image
Push image lên registry
Deploy lên staging
Smoke test trên staging
Approve (manual gate) hoặc auto
Deploy lên production 🚀
Mục đích: Code merge → production trong vài phút, không cần thao tác tay

🐙

GitHub Actions

Tích hợp sẵn GitHub. Free cho public repo. File YAML đơn giản. Marketplace 15,000+ actions.

Miễn phí, dễ setup, cộng đồng lớn, tích hợp GitHub
Phù hợp: Hầu hết dự án web, team mọi size
🦊

GitLab CI/CD

Tích hợp sẵn GitLab. Pipeline mạnh mẽ. Self-hosted runner. Free tier tốt.

All-in-one platform, self-hosted option, Auto DevOps
Phù hợp: Team dùng GitLab, cần self-hosted
🔵

Azure DevOps

Pipeline mạnh cho .NET. Tích hợp Azure cloud. Boards, Repos, Artifacts trong 1.

Ecosystem .NET, Azure integration, enterprise features
Phù hợp: Team .NET, deploy lên Azure
🔴

Jenkins

Open source, self-hosted. Plugin mọi thứ. Cần tự quản lý server.

Tùy biến tuyệt đối, 1800+ plugins, self-hosted
Phù hợp: Enterprise, cần kiểm soát hoàn toàn

📝 GitHub Actions — Ví Dụ Thực Tế

CI cho .NET Backend — .github/workflows/ci.yml
name: CI — Build & Test

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'

      - name: Restore dependencies
        run: dotnet restore

      - name: Build
        run: dotnet build --no-restore --configuration Release

      - name: Test
        run: dotnet test --no-build --configuration Release --verbosity normal
CI cho Frontend React/Next.js
name: CI — Frontend

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - run: npm ci              # Install (deterministic)
      - run: npm run lint         # Code quality
      - run: npm run test -- --ci # Unit tests
      - run: npm run build        # Production build
💡 Mẹo: Dùng npm ci thay npm install trong CI — nó install chính xác version trong package-lock.json, nhanh hơn và deterministic.
