6. Cloud Platforms — Big 3 & Khi Nào Cần

Azure, AWS, GCP — khi nào cần cloud thật sự vs khi nào PaaS là đủ

☁️ Big 3 Cloud — So Sánh Nhanh

Microsoft Azure

Tốt nhất cho .NET
Compute: App Service, Azure Functions, AKS
Database: Azure SQL, Cosmos DB
Storage: Blob Storage, CDN
Auth: Azure AD, B2C
Chọn khi: Team .NET, đã dùng Microsoft stack, enterprise

Amazon AWS

Lớn nhất, nhiều service nhất
Compute: EC2, Lambda, ECS, EKS
Database: RDS, DynamoDB, Aurora
Storage: S3, CloudFront
Auth: Cognito, IAM
Chọn khi: Cần mọi thứ, startup-to-enterprise, job market lớn nhất

Google Cloud (GCP)

Tốt nhất cho AI/ML, Big Data
Compute: Cloud Run, GKE, App Engine
Database: Cloud SQL, Firestore, BigQuery
Storage: Cloud Storage, CDN
Special: Firebase, Vertex AI
Chọn khi: Dùng Firebase, Kubernetes, data/AI workload
💡 Cho người mới: Bạn KHÔNG CẦN cloud cho dự án nhỏ-vừa. Vercel + Railway + Supabase = đủ cho 95% side projects và startup giai đoạn đầu. Chỉ cần cloud khi: scale lớn, cần nhiều managed services, hoặc enterprise yêu cầu.

⚡ Serverless — Không Cần Quản Lý Server

"Viết function → deploy → chỉ trả tiền khi function chạy. Không traffic = $0."

Azure Functions

Serverless cho .NET. Trigger từ HTTP, queue, timer, blob. Free 1 triệu request/tháng.

AWS Lambda

Serverless phổ biến nhất. Mọi ngôn ngữ. Free 1 triệu request/tháng.

Vercel Serverless / Edge Functions

API routes trong Next.js = serverless tự động. Zero config. Chạy ở edge gần user.

Cloudflare Workers

Edge runtime cực nhanh (<5ms cold start). JS/TS/Wasm. Free 100K request/ngày.
