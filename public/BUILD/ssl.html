SSL & Security

HTTPS, Let's Encrypt, security headers, những điều tuyệt đối không bỏ qua khi deploy.

🔒

8. SSL & Bảo Mật Deploy

HTTPS không phải optional — Chrome đánh dấu HTTP là "Not Secure". SEO cũng bị phạt.

🔐 SSL/TLS — HTTPS Hoạt Động Thế Nào?

1. Browser connect → server gửi SSL certificate
2. Browser verify → certificate hợp lệ? Đúng domain? Chưa hết hạn?
3. Handshake → tạo session key để mã hóa traffic
4. Encrypted → mọi data giữa browser ↔ server đều được mã hóa

📋 Lấy SSL Certificate — Các Cách

⭐ MIỄN PHÍ

Let's Encrypt + Certbot

SSL miễn phí, tự động renew. Certbot cài trên server, auto renew mỗi 90 ngày.

# Cài Certbot (Ubuntu)
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d myapp.com -d www.myapp.com
# Auto renew: certbot tự thêm cron job
⭐ ZERO CONFIG

Managed SSL (Vercel, Netlify, Cloudflare)

Tự động cấp + renew. Không cần làm gì. Add custom domain → SSL sẵn trong 30 giây.

Azure App Service Managed Certificate

Free SSL cho custom domain trên Azure. Auto renew. Zero setup.

🛡️ Security Checklist — Trước Khi Go Live

☠️
HTTPS everywhere

Redirect HTTP → HTTPS. Không exception.

☠️
Secrets KHÔNG ở trong code

API keys, DB passwords → environment variables hoặc secret manager. KHÔNG hardcode.

☠️
Security headers

Thêm: X-Content-Type-Options, X-Frame-Options, Content-Security-Policy, Strict-Transport-Security

⚠️
CORS cấu hình đúng

Không dùng * cho production. Chỉ allow domain cụ thể.

⚠️
Rate limiting

API phải có rate limit. Không có = DDoS dễ dàng.

⚠️
Error pages custom

Không để stack trace hiển thị cho user production. Dùng custom 404, 500 pages.

💡
Dependency updates

Bật Dependabot / Renovate — auto tạo PR khi có security update.

💡
Backup strategy

Database backup tự động, test restore định kỳ. "Backup chưa test restore = chưa có backup."
