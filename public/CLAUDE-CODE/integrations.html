Tích hợp Claude Code

MCP servers (Slack, DB, Linear), VS Code + JetBrains extensions, Agent SDK cho automation, GitHub Actions để Claude tự review PR. Đưa Claude vào toàn bộ workflow team.

1. MCP — Model Context Protocol

MCP là chuẩn open-source để kết nối AI với external system. Claude Code hỗ trợ MCP full native — kết nối tới Slack, GitHub, Linear, Postgres, Notion, và hàng trăm server khác.

💡 MCP làm gì?

Mở rộng khả năng của Claude bằng thêm tool. Ví dụ:

  • MCP Slack → Claude có tool send_message
  • MCP Postgres → tool query để đọc DB
  • MCP GitHub → tool create_issue, review_pr
  • MCP Filesystem → đọc file ngoài workspace

🏗 Kiến trúc

MCP server = process riêng, expose tool qua JSON-RPC.

┌──────────────┐
│ Claude Code  │
└──────┬───────┘
       │ stdio / HTTP
┌──────▼───────┐
│  MCP server  │
│ (slack, db…) │
└──────────────┘

Thêm MCP server — các cách

# Cách 1: CLI (khuyên dùng)
claude mcp add slack --env SLACK_BOT_TOKEN=xoxb-... -- npx @modelcontextprotocol/server-slack

# Cách 2: Sửa settings.json
{
  "mcpServers": {
    "slack": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-slack"],
      "env": {
        "SLACK_BOT_TOKEN": "xoxb-..."
      }
    }
  }
}

# Kiểm tra server đã connect
claude mcp list

Ví dụ dùng MCP Postgres

You: How many users signed up last week? Claude: I'll query the database. ● mcp__postgres__query( SELECT count(*) FROM users WHERE created_at > now() - interval '7 days' ) ⎿ { count: 1847 } 1,847 users signed up in the last 7 days. Want breakdown by day?
Tìm thêm MCP server: github.com/modelcontextprotocol/servers — list chính thức. Hoặc Google "MCP server <tool-name>".

2. IDE Extensions

🎨 VS Code Extension

Cài: Extensions marketplace → search "Claude Code" → Install.

Tính năng:

  • Sidebar panel riêng cho Claude
  • Inline suggestion như Copilot
  • Quick edit: chọn code → Ctrl+I → prompt edit
  • Command Palette: Claude: New session, Claude: Review file
  • Auto sync với CLI session đang chạy
Tip: Chạy /ide trong CLI để pair với VS Code đang mở → Claude sync với file user đang edit.

🧪 JetBrains Plugin

Cài: Settings → Plugins → Marketplace → "Claude Code".

Support: IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider, RubyMine, PhpStorm, CLion.

Tính năng:

  • Tool window riêng
  • Selection actions: right-click → Claude: Explain/Refactor
  • Integrate run config, debugger
  • Version control integration

3. Claude Agent SDK — Build automation

Khi bạn muốn Claude Code chạy programmatic (script, cron, webhook handler) — dùng Agent SDK.

🐍 Python SDK

# pip install anthropic-agent-sdk
import asyncio
from anthropic_agent_sdk import query

async def main():
    async for message in query(
        prompt="Fix all lint errors in this repo",
        cwd="/path/to/repo",
        allowed_tools=["Bash", "Edit", "Read"],
        model="claude-sonnet-4-6",
    ):
        print(message)

asyncio.run(main())

📘 TypeScript SDK

// npm install @anthropic-ai/agent-sdk
import { query } from '@anthropic-ai/agent-sdk';

for await (const message of query({
  prompt: 'Summarize recent commits',
  cwd: process.cwd(),
  allowedTools: ['Bash', 'Read'],
  maxTurns: 10,
})) {
  console.log(message);
}

Use case: Daily report bot

# Cron chạy mỗi sáng — Claude tổng kết PR team + post Slack
import asyncio
from anthropic_agent_sdk import query

async def daily_report():
    prompt = """
    1. List all PRs merged yesterday (git log, github MCP)
    2. Categorize: feat / fix / chore / refactor
    3. Post summary to Slack #dev-daily (use slack MCP)
    """

    async for msg in query(
        prompt=prompt,
        allowed_tools=["Bash", "mcp__github__*", "mcp__slack__*"],
        max_turns=20,
    ):
        pass

asyncio.run(daily_report())
Khi nào dùng SDK vs CLI --print?
  • CLI --print: script 1-off, shell pipeline, CI step
  • SDK: chương trình phức tạp, nhiều agent, streaming output, custom UI

4. GitHub Actions — Claude tự review PR

Setup secrets

# Repo Settings → Secrets → Actions
ANTHROPIC_API_KEY=sk-ant-api03-...  # lấy từ console.anthropic.com

Workflow auto-review PR

# .github/workflows/claude-review.yml
name: Claude PR Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
      contents: read
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }

      - uses: actions/setup-node@v4
        with: { node-version: '20' }

      - name: Install Claude Code
        run: npm install -g @anthropic-ai/claude-code

      - name: Review PR
        run: |
          claude --print --dangerously-skip-permissions \
            "Review the PR diff against main. Output markdown feedback grouped by Critical/Major/Minor. Then post as PR comment using gh CLI."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

Workflow khác — Claude sửa lint/test fail

name: Auto-fix failing tests
on:
  workflow_dispatch:
  schedule:
    - cron: '0 9 * * 1-5'  # mỗi sáng workday

jobs:
  fix:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci

      - name: Claude fix failing tests
        run: |
          npm install -g @anthropic-ai/claude-code
          claude --print --dangerously-skip-permissions "
            Run npm test. If tests fail, analyze and fix each one.
            Commit to branch auto-fix/tests with descriptive message.
            Create PR with list of fixed tests.
          "
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

5. Background Agents — Task chạy hàng giờ

Task lớn (refactor toàn codebase, migrate hundreds of files) — chạy Claude background, kiểm tra kết quả sau.

📱 Qua claude.ai/code web

Anthropic hỗ trợ "background tasks" native:

  • Gõ task → Run in background
  • Claude chạy trong cloud sandbox
  • Bạn đóng browser được — task vẫn chạy
  • Nhận email/notification khi xong
  • Review diff, commit/PR từ web

💻 Qua CLI + screen/tmux

# Chạy Claude trong tmux session
tmux new -s claude-refactor
claude --print "Large refactor task..."
# Ctrl+B D để detach

# Quay lại sau
tmux attach -t claude-refactor

6. Cloud deployment — Claude API qua proxy

Triển khai Claude Code như service nội bộ của team.

// proxy.ts — Express app wrap Claude SDK
import express from 'express';
import { query } from '@anthropic-ai/agent-sdk';

const app = express();
app.use(express.json());

app.post('/task', async (req, res) => {
  const { prompt, repo } = req.body;

  // Clone repo sang tmp
  const workdir = await cloneRepo(repo);

  const messages = [];
  for await (const msg of query({
    prompt,
    cwd: workdir,
    allowedTools: ['Read', 'Edit', 'Bash'],
  })) {
    messages.push(msg);
  }

  res.json({ messages, diff: await getDiff(workdir) });
});

app.listen(3000);
Use case: Slack slash command /claude fix the bug X → hit proxy → Claude work → kết quả post ngược lại Slack.

7. Remote Triggers & Scheduled Tasks

Trigger Claude từ outside:

🌐 Remote Trigger

Claude Code CLI hỗ trợ trigger từ webhook — đăng ký URL, HTTP POST tới URL đó → Claude chạy trong session hiện tại.

Use case: Trigger Claude từ dashboard nội bộ.

⏰ Cron / Scheduled

Dùng CronCreate tool trong Claude Code Web / Managed Agents. Setup task chạy định kỳ (mỗi sáng, mỗi giờ).

Use case: Daily changelog, weekly dependency audit.

🔁 Loop mode

Slash command /loop 5m /check-build → Claude tự chạy /check-build mỗi 5 phút cho đến khi interrupt.

Use case: Poll deployment status.

💡 Bài tập

  1. Cài MCP filesystem — add 1 folder ngoài workspace (ví dụ ~/Documents) cho Claude đọc.

  3. Script với SDK — viết Python script dùng Agent SDK để in tổng số line code của project.
  4. GitHub Action review — setup workflow auto-review PR trên 1 repo test.
  5. MCP Postgres — connect Claude vào Postgres local, yêu cầu "đếm số row table X".
