Claude Code là gì?

💡 Định nghĩa 30 giây

Claude Code là AI coding agent của Anthropic. Khác ChatGPT ở chỗ: nó thực sự thao tác được với máy của bạn — đọc/sửa file, chạy lệnh shell, gọi git, chạy test. Bạn mô tả việc cần làm, nó suy nghĩ và thực thi từng bước.

3 dạng sử dụng:

  • CLI terminal — claude command
  • IDE extension — VS Code, JetBrains
  • Web — claude.ai/code (không cần cài)
  • SDK — Python/TypeScript cho automation

⚡ Tại sao khác biệt?

  • Agentic — tự lập plan, thực thi, tự kiểm tra, sửa khi sai
  • Context window 1M+ token (Opus) — đọc được cả codebase
  • Long-running tasks — làm task nhiều giờ không đứt
  • Tích hợp sâu git — tự commit, PR, review
  • Extensible — hooks, slash commands, skills, MCP, subagents
  • Model Claude mới nhất — Opus 4.7, Sonnet 4.6, Haiku 4.5

Khi nào dùng Claude Code?

✅ Dùng khi

  • Refactor lớn — rename hàm xuyên codebase, đổi pattern
  • Bug fix đòi hỏi đọc nhiều file — trace error qua nhiều layer
  • Viết test cho code hiện có
  • Implement feature theo spec — từ ticket → code + test + PR
  • Explore codebase lạ — "code này làm gì?"
  • Automation — viết script, CI pipeline, migration
  • Code review — tự động check PR
  • Học tech mới — Claude giải thích + demo ngay

❌ Ít hữu ích khi

  • Task quá nhỏ — đổi 1 dòng, gõ tay còn nhanh hơn prompt
  • Design thuần UI/UX — cần Figma, không phải code
  • Quyết định business logic — Claude không biết context thị trường
  • Code security/compliance cao — cần human review kỹ
  • Offline environment — Claude cần internet

Quy tắc: task càng có scope rõ ràng, càng cần đọc nhiều code, càng hợp với Claude Code. Task mơ hồ hoặc cần sáng tạo → bạn lead, Claude hỗ trợ.

Claude Code chạy ngay trên browser — không cài gì, không cần Node.js. Link GitHub repo vào, Claude code trong container cloud do Anthropic host.

  • Zero setup
  • Miễn phí với Claude Pro/Max
  • Giống hệt CLI nhưng UI đẹp hơn

💻 CLI — cho control tối đa

Dùng khi cần thao tác với repo local, chạy đồng thời với IDE của bạn.

# Cài một lệnh
npm install -g @anthropic-ai/claude-code

# Login lần đầu
claude

# Browser mở để auth
# → xong, ready to go

Cần Node.js 18+. Chi tiết ở trang Cơ Bản.

Demo 60 giây — Claude Code làm gì?

$ claude # Claude Code khởi động trong repo hiện tại You: Read CLAUDE.md and summarize this project in 3 sentences. Claude: I'll read the file first. # [Reads CLAUDE.md] This is DevHub — a React SPA learning hub that loads static HTML pages via iframes. Content is organized around .NET, SQL, Build/Deploy, languages, English, AI, and tips. Uses localStorage for progress tracking. You: Add a new section 'Rust' to the sidebar, with a hub page that has the same style as the Redis section. Claude: I'll do this in 3 steps: 1. Create public/RUST/ folder with index.html using Redis styling 2. Register section in src/App.jsx SECTIONS 3. Add stat card in Dashboard.jsx # [Reads Redis folder, copies style pattern] # [Writes public/RUST/index.html - 240 lines] # [Edits src/App.jsx - adds rust entry] # [Edits Dashboard.jsx - adds card] ✓ Done. Created 1 file, edited 2 files. Restart npm run dev and click 🦀 Rust in sidebar to see it.

Đó là 1 request bình thường. Claude đọc code cũ để bắt chước pattern, tạo file mới, sửa 2 file React — đúng chỗ. Không copy-paste từ Stack Overflow, không hallucination tên file không có.

Checklist tự đánh giá

✅ Beginner (L1)

  • Cài được claude CLI hoặc mở được web
  • Login thành công
  • Hỏi Claude đọc file, hiểu output
  • Cho Claude sửa 1 file đơn giản
  • Biết 3 permission mode
  • Tạo file CLAUDE.md

✅ Junior (L2)

  • Dùng /compact /clear /model
  • Đổi model giữa chừng session
  • Plan mode trước khi làm task lớn
  • Cho Claude commit + push
  • Đọc/hiểu Claude plan, chấp thuận hoặc bác

✅ Mid (L3)

  • Viết 2-3 slash command riêng
  • Setup hook auto-format sau edit
  • Dùng Agent subagent cho task nặng
  • Cấu hình .claude/settings.json
  • Tạo skill riêng cho project

✅ Senior (L4)

  • Setup MCP server (filesystem, GitHub)
  • Viết script tự động bằng Agent SDK
  • Tích hợp Claude Code vào GitHub Actions
  • Background agent chạy task giờ
  • Multi-agent workflow (planner + worker + reviewer)

✅ Master (L5)

  • Thiết kế CLAUDE.md 200-300 dòng cho project phức tạp
  • Chia task theo pattern "Explore → Plan → Act → Review"
  • Biết khi nào nên interrupt Claude
  • Dùng Claude để review đồng nghiệp
  • Train team mới dùng Claude Code hiệu quả

🎯 Dự án luyện

  • Fix bug trong repo lớn lạ
  • Viết 100% test cho module sẵn có
  • Migrate project CRA → Vite
  • Tạo script tự release changelog
  • Build mini SaaS từ prompt đến deploy
