2. Các command dùng nhiều nhất — đi sâu

/clear vs /compact — khi nào dùng?

/clear

Xoá sạch conversation, như bắt đầu session mới. Giữ CLAUDE.md nhưng mất toàn bộ thảo luận trước.

Dùng khi: chuyển hẳn sang task mới, không liên quan.

/compact

Claude tóm tắt conversation dài thành 1 summary ngắn, giữ các fact chính để tiếp tục. Không mất context.

Dùng khi: context window gần đầy, cần tiếp task đang dở.

Dấu hiệu cần compact: Claude trả lời chậm hẳn, hoặc bắt đầu "quên" những gì đã nói đầu session. Gõ /compact ngay.

/model — Chọn đúng model cho đúng task

ModelKhi dùngTốc độChi phí / 1M token
Opus 4.7Task phức tạp, reasoning nặng, refactor lớn, designChậm~$15-75
Sonnet 4.6Default — cân bằng tốt cho 90% taskVừa~$3-15
Haiku 4.5Task đơn giản, format, rename, simple editsNhanh~$1-5

Chiến lược: Mặc định Sonnet. Gặp task khó (multi-file refactor, architecture) → /model opus. Task vặt → /model haiku.

/init — Sinh CLAUDE.md tự động

You: /init Claude: I'll analyze the repository structure and create CLAUDE.md. ● Glob(**/*.json) ● Read(package.json) ● Read(README.md) ● Glob(src/**/*.ts) ● Bash(git log --oneline -20) ● Write(CLAUDE.md) ⎿ Wrote 87 lines ✓ Created CLAUDE.md. Review it and customize for your workflow.

3. Plan Mode — "Hãy nghĩ trước khi hành động"

Chế độ đặc biệt: Claude chỉ plan, không edit file / chạy lệnh. Bạn review plan, approve mới thực thi.

# Vào plan mode — 2 cách

# 1. Gõ lệnh
/plan

# 2. Hoặc phím tắt khi đang gõ prompt
Shift+Tab # cycle đến Plan Mode
You: Implement OAuth Google login Claude [Plan Mode]: Let me plan this. ● Read(src/auth/*.ts) ● Read(package.json) Plan: 1. Install next-auth package 2. Create src/lib/auth.ts với Google provider 3. Add GOOGLE_CLIENT_ID/SECRET to .env.example 4. Wrap app in SessionProvider 5. Replace manual auth in src/pages/login.tsx 6. Update middleware để bảo vệ routes 7. Add test cho login flow [Plan Mode - no changes made yet. Approve? Y/n/edit] You: edit Skip step 6 — middleware đã có sẵn. Giữ còn lại. Claude: Got it. Executing steps 1-5, 7.
Khi nào dùng Plan Mode?
  • Task lớn đụng nhiều file (>5)
  • Refactor architecture
  • Bạn chưa rõ Claude sẽ làm gì
  • Dùng permission mode YOLO cho safe

4. CLI Flags — Headless & automation

Chạy Claude từ script, CI pipeline — không cần session tương tác.

# Chạy 1 prompt, xong thì exit
claude --print "Summarize this codebase in 3 bullet points"

# Output JSON (machine readable)
claude --print --output-format json "List all TODOs"

# Append system prompt
claude --append-system-prompt "Always use TypeScript"

# Chọn model
claude --model opus "Refactor this module"

# Non-interactive — auto accept mọi thao tác (DANGEROUS, dùng cho CI)
claude --dangerously-skip-permissions --print "Fix all lint errors"

# Chạy trong thư mục khác
claude --cwd /path/to/other/project

# Verbose logs để debug
claude --debug

Ví dụ thực tế — lint fixer CI step

# .github/workflows/ci.yml
- name: Auto-fix lint with Claude
  run: |
    npm install -g @anthropic-ai/claude-code
    claude --print --dangerously-skip-permissions \
      "Run npm run lint. Fix all errors. Commit with message 'chore: lint fixes'."
  env:
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

Khi Claude đang chạy

PhímCông dụng

Esc EscInterrupt + rewind 1 turn
YAccept prompt yes/no
NReject
Ctrl+LClear screen (giữ context)

Pro shortcut: Esc Esc cực kỳ hữu ích. Claude đi nhầm hướng → nhấn 2 lần Esc, Claude rewind về bước trước cuối cùng, sửa prompt rồi gõ lại.

6. Reference file trong prompt

Ký hiệu @ + tên file để Claude tự động đọc file đó vào context.

# Ví dụ
Compare @src/old-impl.ts with @src/new-impl.ts
and explain why new one is faster.

# Reference folder
Scan @src/components/ and list all files that use
deprecated 'useEffect' with empty deps.

# Reference với glob (tab-complete giúp)
Fix TypeScript errors in @src/pages/**/*.tsx

Khi gõ @, Claude Code tự động gợi ý file có sẵn trong repo. Tab để chọn.

7. Paste screenshot / image

Claude hiểu ảnh — paste screenshot UI lỗi, Figma mockup, diagram vào prompt.

Windows / Linux

Chụp screenshot → Ctrl+V trong terminal Claude. Terminal hỗ trợ paste image (Windows Terminal, WezTerm, iTerm2, …).

Hoặc path file

Đây là mockup cần implement:
@./design/mockup.png

Viết component React match design này.
Use case phổ biến: "Đây là screenshot bug, debug giúp", "Implement UI theo mockup này", "Đọc diagram kiến trúc và giải thích".
