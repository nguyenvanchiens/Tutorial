0-1 NĂM

Fresher .NET Developer

8 - 12 triệu

Mới ra trường hoặc < 1 năm kinh nghiệm. Cần nắm vững C# cơ bản, OOP, SQL cơ bản.

C# BasicsOOPSQLGit
Vòng 1: Kiến thức nền tảng (5 câu)
Vòng 2: Đọc code & Debug (5 câu)
Vòng 3: Code Challenge (3 câu)
1-3 NĂM

Junior .NET Developer

12 - 20 triệu

1-3 năm kinh nghiệm. Hiểu ASP.NET Core, EF Core, biết viết API, hiểu DI, unit test cơ bản.

ASP.NET CoreEF CoreREST APIDIUnit Test
Vòng 1: Kiến thức kỹ thuật (5 câu)
Vòng 2: Tìm Bug & Debug (5 câu)
Vòng 3: Code Review + Refactor (4 câu)
3-5 NĂM

Middle .NET Developer

20 - 35 triệu

3-5 năm. Tự chủ hoàn thành features phức tạp. Hiểu architecture, security, performance tuning.

Clean ArchitectureCQRSSecurityPerformanceDocker
Vòng 1: Deep Technical (5 câu)
Vòng 2: Bug Hunt + Performance (5 câu)
Vòng 3: System Design (3 câu)
Vòng 4: Tình huống Production (3 câu)
5-8 NĂM

Senior .NET Developer

35 - 55 triệu

5+ năm. Lead technical decisions, mentor juniors. Hiểu distributed systems, microservices, DevOps.

MicroservicesDistributedCI/CDMentoringDesign Patterns

Vòng 3: Production War Stories (4 câu)
Vòng 4: Leadership & Decision Making (3 câu)
7+ NĂM

Tech Lead / Architect

55 - 80+ triệu

7+ năm. Định hướng kỹ thuật cho team/product. Trade-off decisions, team building, stakeholder management.

System DesignTeam LeadingTrade-offsScalabilityStrategy
Vòng 1: System Architecture (5 câu)
