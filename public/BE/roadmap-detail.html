  • Collections: List, Dictionary, HashSet, Queue, Stack — khi nào dùng cái nào

Bài tập thực hành

  • Console app quản lý sinh viên (CRUD in-memory)
  • Viết class Library + Consumer app
  • Implement các design patterns đơn giản: Singleton, Factory
  • Giải 50 bài LeetCode Easy bằng C#

Công cụ & Technologies phải biết

Hàng ngày phải dùng

Docker

Containerize app, docker-compose cho local dev. Không biết Docker = không deploy được.

Git

Advanced: rebase, cherry-pick, bisect, reflog. Git là time machine — phải dùng thành thạo.

Postman / Bruno / Thunder Client

API testing, collections, environments. Bruno (open source) đang lên.

VS Code / Visual Studio / Rider

Thành thạo IDE: shortcuts, debugger, refactoring tools. Rider mạnh nhất cho .NET.

SQL Server Management Studio / Azure Data Studio

Query, execution plan, profiler. Azure Data Studio nhẹ hơn, cross-platform.

Phải biết khi lên Senior

Redis

Distributed cache, session store, pub/sub, rate limiting. Dùng rất nhiều trong production.

RabbitMQ / Kafka

Message queue cho async processing. RabbitMQ đơn giản hơn. Kafka cho scale lớn + event streaming.

Elasticsearch / OpenSearch

Full-text search, log aggregation (ELK stack). Khi SQL LIKE '%keyword%' không đủ nhanh.

Kubernetes

Container orchestration. Hiểu concepts: pods, services, deployments, ingress. Không cần expert nhưng phải hiểu.

Terraform / Bicep

Infrastructure as Code. Tạo cloud resources bằng code thay vì click UI.

Grafana + Prometheus / Application Insights

Monitoring, alerting, dashboards. "If you can't measure it, you can't improve it."

Mở rộng khi có thời gian

SignalR

Real-time communication: chat, notifications, live dashboards.

GraphQL (HotChocolate)

Alternative cho REST khi client cần flexible queries. Không thay thế REST — bổ sung.

Dapr

Distributed Application Runtime — simplify microservices development.

Blazor

C# trên browser. Hữu ích khi cần full-stack C# — nhưng không thay thế React/Angular.

Training Plan — Dùng Cho Team

Copy plan này để training Fresher/Junior trong team. Đã test thực tế.

Fresher Onboarding (8 tuần)

Mục tiêu: Sau 8 tuần, fresher tự deliver được feature đơn giản end-to-end.

Tuần 1-2
C# + Project Structure

Đọc code project, hiểu structure. Viết console app recap C#. Code review 1-on-1.

Tuần 3-4
ASP.NET Core + Database

Viết 1 API endpoint mới. Pair programming với senior. Hiểu DI, middleware, EF Core.

Tuần 5-6
Testing + Git workflow

Viết unit tests cho feature. Tạo PR đầu tiên. Nhận code review, iterate.

Tuần 7-8
Solo Feature

Tự deliver 1 feature nhỏ end-to-end: design → implement → test → PR → deploy.

Definition of Done: Fresher tự tạo PR chất lượng, có tests, qua code review ≤ 2 rounds.

Junior → Mid Growth Plan (6 tháng)

Mục tiêu: Junior bắt đầu own component/module, tự ra technical decisions nhỏ.

Tháng 1-2
Deep Dive + Ownership

Own 1 module/service. Viết tech spec trước khi code. Bắt đầu review code người khác.

Tháng 3-4
Architecture + Performance

Refactor 1 phần code theo Clean Architecture. Optimize 1 slow query. Setup caching.

Tháng 5-6
Leadership Lite

Mentor 1 fresher. Viết ADR cho 1 technical decision. Present tech topic cho team.

Definition of Done: Junior tự estimate, design, implement features phức tạp. Code review quality cao. Bắt đầu mentor người khác.

Mid → Senior Acceleration (12 tháng)

Mục tiêu: Think in systems, not just features. Own technical direction.

Q1
System Thinking

Design 1 feature end-to-end bao gồm scalability, security, monitoring. Viết RFC cho team review.

Q2
Cross-team Impact

Solve 1 cross-team technical problem. Setup shared library/package. Improve CI/CD pipeline.

Q3
Production Ownership

Own production incidents. Setup monitoring + alerting. Blameless post-mortem.

Q4
Technical Leadership

Lead 1 technical initiative. Present architecture proposal. Đánh giá và adopt new technology.

Definition of Done: Team và stakeholders tin tưởng technical decisions. Tự drive technical direction không cần guidance.
