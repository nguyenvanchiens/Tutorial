Redis là gì?

💡 Định nghĩa 30 giây

Redis (Remote Dictionary Server) là in-memory key-value store. Dữ liệu nằm trong RAM → đọc/ghi <1ms. Hỗ trợ 9 kiểu dữ liệu (không chỉ string), có persistence, replication, cluster.

Công dụng chính: cache (90% use case), session store, rate limit, queue, real-time counter, leaderboard, pub/sub, distributed lock.

⚡ Tại sao nhanh?

  • Dữ liệu trong RAM, không đọc disk
  • Single-threaded cho command — không lock/context switch
  • Network I/O dùng epoll/kqueue (non-blocking)
  • Cấu trúc dữ liệu tối ưu sẵn (hash table, skiplist, radix tree)
  • ~100k ops/s trên 1 instance rẻ tiền

Khi nào dùng Redis?

✅ Dùng khi

  • Cache kết quả DB query — giảm 90% tải DB
  • Session store — nhiều server share session
  • Rate limiting — chặn spam API
  • Queue đơn giản — task async cho worker
  • Real-time counter — view count, like count
  • Leaderboard — top N theo điểm, sorted set
  • Pub/Sub — real-time notification đơn giản
  • Distributed lock — đảm bảo chỉ 1 worker xử lý job

❌ KHÔNG dùng khi

  • Database chính — RAM mắc gấp 100 lần disk
  • Lưu file/blob lớn — dùng S3/CDN
  • Phân tích phức tạp — dùng Postgres/ClickHouse
  • Full-text search — dùng Elasticsearch (hoặc RediSearch module riêng)
  • Queue nặng, đảm bảo delivery — dùng RabbitMQ/Kafka
  • Transaction phức tạp đa bước — Redis MULTI/EXEC hạn chế
Quy tắc vàng: Redis là bổ trợ cho DB chính, không thay thế. 95% use case thực tế: Postgres/SQL Server lưu dữ liệu gốc + Redis cache kết quả tra cứu nóng.

⚡ Dùng Redis KHÔNG cần cài

Giống Docker, Redis cài local có thể nặng máy. 4 cách dùng nhanh không cần install.

🌐 1. try.redis.io — Playground web

URL: try.redis.io

Terminal Redis ngay trên browser, có tutorial hướng dẫn từng bước. Zero setup, chỉ mở tab mới và gõ.

✅ Tuyệt cho học lệnh lần đầu

☁️ 2. Upstash — Serverless Redis KHUYÊN DÙNG

URL: upstash.com

Free tier 10,000 commands/ngày, 256MB. Tạo DB trong 30 giây, lấy connection string, dùng REST API hoặc Redis protocol.

✅ Làm project thật mà không tốn byte RAM nào

☁️ 3. Redis Cloud — Free 30MB

URL: redis.com/try-free

Của chính Redis Inc. — 30MB miễn phí vĩnh viễn, chạy trên AWS/GCP/Azure. Full Redis 7.4 với modules (RediSearch, JSON).

🐳 4. Docker one-liner

Nếu đã có Docker / Podman:

docker run -d --name redis -p 6379:6379 redis:7

# Kết nối CLI trong container
docker exec -it redis redis-cli
Khuyên dùng: bắt đầu bằng try.redis.io để học lệnh → dùng Upstash khi code project thật. Chỉ cài local khi thực sự cần dev offline.

Redis vs Memcached vs DB

Redis Memcached Postgres (cache table)
Data types 9 kiểu: String, List, Hash, Set, Sorted Set, Stream, Bitmap, HyperLogLog, Geo Chỉ string Row với columns
Persistence RDB snapshot + AOF log Không (tắt máy = mất) Đầy đủ (WAL)
Tốc độ ~100k ops/s ~200k ops/s (đơn giản hơn) ~10k ops/s
Replication/HA Có (Sentinel, Cluster) Hạn chế Có (streaming replication)
Pub/Sub, Stream Có sẵn Không NOTIFY/LISTEN cơ bản
Khi chọn Cache + thêm nhiều tính năng Cache duy nhất, string đơn giản Dữ liệu chính
Quyết định nhanh: 90% team chọn Redis — linh hoạt, đa năng, community lớn. Memcached chỉ thắng khi bạn thật sự chỉ cần cache string và cần squeeze performance cao nhất.

Checklist tự đánh giá

✅ Beginner (L1)

  • Chạy Redis (Upstash hoặc Docker)
  • Dùng được SET/GET/DEL
  • Set TTL bằng EXPIRE
  • Phân biệt String/List/Hash/Set
  • Kết nối từ app backend đầu tiên

✅ Junior (L2)

  • Dùng Sorted Set cho leaderboard
  • Pipelining để tiết kiệm RTT
  • Dùng SCAN thay KEYS
  • Viết Lua script đơn giản
  • Hiểu single-threaded model

✅ Mid-level (L3)

  • Implement cache-aside đúng
  • Rate limit bằng sliding window
  • Distributed lock với TTL
  • Dựng queue bằng List hoặc Stream
  • Xử lý cache stampede, hot key

✅ Senior (L4)

  • Chọn đúng persistence (RDB/AOF/cả hai)
  • Setup Sentinel cho HA
  • Phân shard với Cluster
  • Cấu hình maxmemory + eviction
  • Monitor SLOWLOG, latency

🎯 Dự án luyện

  • Cache API response trong Next.js/ASP.NET
  • Rate limit IP login (5 lần/phút)
  • Leaderboard game top 100
  • Session store cho app multi-server
  • Mini chat bằng Pub/Sub
