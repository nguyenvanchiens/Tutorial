2. C# / .NET — Ngôn Ngữ Chính Của Bạn

Dù đã biết — vẫn cần biết ecosystem đầy đủ. Đây là "home base" để so sánh với mọi ngôn ngữ khác.

⚡ C# 80/20 — Những Thứ Bạn Đã Biết (Recap Nhanh)

Core Syntax — Nền tảng so sánh
// Record (C# 9+) — immutable DTO
public record User(
    int Id,
    string Name,
    string Email,
    bool IsActive = true
);

// Interface + DI
public interface IUserRepository
{
    Task<User?> FindByIdAsync(int id);
    Task<User> CreateAsync(User user);
}

// Minimal API (ASP.NET Core 8+)
var app = WebApplication.CreateBuilder(args).Build();

app.MapGet("/api/users/{id}", async (int id, IUserRepository repo) =>
{
    var user = await repo.FindByIdAsync(id);
    return user is not null
        ? Results.Ok(user)
        : Results.NotFound();
});

app.MapPost("/api/users", async (User user, IUserRepository repo) =>
    Results.Created($"/api/users/{user.Id}", await repo.CreateAsync(user)));

app.Run();
Đây là baseline: Mỗi ngôn ngữ phía dưới sẽ so sánh trực tiếp với C# code ở trên. Record = struct/data class. Interface = trait/protocol. DI = constructor injection. Minimal API = route handler.
C# Modern Features — Cần biết để so sánh công bằng
// Pattern matching (C# 11+)
var result = user switch
{
    { IsActive: true, Role: "admin" } => "Welcome, admin!",
    { IsActive: true }                  => "Welcome, user!",
    _                                     => "Account inactive"
};

// Primary constructor (C# 12)
public class UserService(IUserRepository repo, ILogger<UserService> logger)
{
    public async Task<User> GetUserAsync(int id) =>
        await repo.FindByIdAsync(id)
        ?? throw new NotFoundException($"User {id} not found");
}

// LINQ — sức mạnh query của C#
var activeAdmins = users
    .Where(u => u.IsActive && u.Role == "admin")
    .OrderBy(u => u.Name)
    .Select(u => new { u.Name, u.Email })
    .ToList();

// Async streams (C# 8+)
await foreach (var item in GetItemsAsync())
{
    Console.WriteLine(item);
}

3. Go (Golang) — Đơn Giản, Nhanh, Concurrent

Google tạo năm 2009. Triết lý: "Less is more". Không OOP truyền thống, không generics phức tạp, không exceptions.

⚡ Go 80/20 — Cốt Lõi Cần Nắm

Hello World + cấu trúc cơ bản
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
vs C#: Không cần class, không cần namespace. File .go = package. func main() = entry point.
Variables, Types, Structs
// Khai báo biến
var name string = "Minh"
age := 25                    // Short declaration (tự suy type)
isActive := true

// Struct = class trong C# (nhưng không có inheritance)
type User struct {
    ID       int       `json:"id"`
    Name     string    `json:"name"`
    Email    string    `json:"email"`
    IsActive bool      `json:"is_active"`
}

// Method trên struct (giống method trong C# class)
func (u User) FullName() string {
    return u.Name
}

// Interface (giống C# interface — implicit implementation!)
type Repository interface {
    FindByID(id int) (*User, error)
    Save(user *User) error
}
vs C#: Go KHÔNG CÓ class, inheritance, constructor. Dùng struct + composition. Interface implicit — không cần : IRepository.
Error Handling — Không có try/catch!
// Go trả về error như giá trị thường — PHẢI check
func GetUser(id int) (*User, error) {
    user, err := db.FindByID(id)
    if err != nil {
        return nil, fmt.Errorf("failed to get user %d: %w", id, err)
    }
    return user, nil
}

// Gọi function → PHẢI handle error
user, err := GetUser(42)
if err != nil {
    log.Fatal(err)    // hoặc return err
}
fmt.Println(user.Name)
vs C#: Không có try/catch/throw. Error là return value. Pattern if err != nil xuất hiện khắp nơi — ban đầu verbose nhưng code explicit hơn.
Goroutines & Channels — Concurrent siêu dễ
// Goroutine = lightweight thread (giống Task trong C# nhưng nhẹ hơn 1000x)
func main() {
    // Chạy 3 API calls đồng thời
    results := make(chan string, 3)

    go fetchAPI("users", results)     // go = chạy goroutine
    go fetchAPI("products", results)
    go fetchAPI("orders", results)

    // Đợi 3 kết quả
    for i := 0; i < 3; i++ {
        fmt.Println(<-results)       // <- đọc từ channel
    }
}

func fetchAPI(name string, ch chan string) {
    // ... fetch data ...
    ch <- fmt.Sprintf("%s: done", name)  // gửi kết quả vào channel
}
vs C#: go func() = Task.Run(). Channel = giống Channel<T> trong C#. Nhưng goroutine nhẹ hơn nhiều — chạy hàng triệu goroutine bình thường.
HTTP API với standard library (không cần framework!)
package main

import (
    "encoding/json"
    "net/http"
)

func main() {
    http.HandleFunc("/api/users", handleUsers)
    http.ListenAndServe(":8080", nil)
}

func handleUsers(w http.ResponseWriter, r *http.Request) {
    users := []User{
        {ID: 1, Name: "Minh", Email: "minh@email.com"},
    }
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(users)
}
vs C#: Go standard library đủ mạnh cho API — không bắt buộc framework. Nếu cần router/middleware: dùng Chi, Gin, hoặc Fiber.

4. Rust — An Toàn, Cực Nhanh, Zero-Cost Abstractions

Memory safe mà KHÔNG cần garbage collector. Nhanh ngang C/C++. Khó học nhất nhưng đáng giá nhất.

⚡ Rust 80/20 — Cốt Lõi Cần Nắm

Variables, Types, Ownership
// Biến immutable mặc định (ngược C#!)
let name = "Minh";           // immutable
let mut age = 25;            // mutable (phải khai báo mut)

// Struct
struct User {
    id: u32,
    name: String,
    email: String,
    is_active: bool,
}

// Implement methods (giống partial class)
impl User {
    fn new(name: String, email: String) -> User {
        User { id: 0, name, email, is_active: true }
    }

    fn display_name(&self) -> &str {
        &self.name
    }
}

// ⭐ OWNERSHIP — khái niệm quan trọng nhất của Rust
let s1 = String::from("hello");
let s2 = s1;          // s1 MOVED sang s2 → s1 không dùng được nữa!
// println!("{}", s1); // ❌ Compile error: value moved
println!("{}", s2);    // ✅ OK
Ownership = khác biệt lớn nhất vs mọi ngôn ngữ khác. Mỗi value có 1 owner. Khi owner ra khỏi scope → value tự giải phóng. Không cần GC, không memory leak, không null pointer.
Error Handling — Result<T, E> và Option<T>
// Rust không có null, không có exceptions
// Option<T> = có hoặc không có giá trị (thay null)
fn find_user(id: u32) -> Option<User> {
    if id == 1 {
        Some(User::new("Minh".into(), "minh@email.com".into()))
    } else {
        None
    }
}

// Result<T, E> = thành công hoặc lỗi (thay try/catch)
fn get_user(id: u32) -> Result<User, String> {
    let user = find_user(id)
        .ok_or(format!("User {} not found", id))?;  // ? = propagate error
    Ok(user)
}

// Pattern matching — cực mạnh
match get_user(42) {
    Ok(user) => println!("Found: {}", user.name),
    Err(e)   => println!("Error: {}", e),
}
vs C#: Option<T> = Nullable<T> nhưng bắt buộc check. Result<T,E> = exception handling compile-time. ? operator = throw tự động.
Traits — Giống interface nhưng mạnh hơn
// Trait = interface + default implementation
trait Repository {
    fn find_by_id(&self, id: u32) -> Option<User>;
    fn save(&self, user: &User) -> Result<(), String>;

    // Default method (giống default interface method C# 8)
    fn exists(&self, id: u32) -> bool {
        self.find_by_id(id).is_some()
    }
}

// Implement trait cho struct
impl Repository for PostgresRepo {
    fn find_by_id(&self, id: u32) -> Option<User> {
        // query database...
    }
    fn save(&self, user: &User) -> Result<(), String> {
        // insert/update...
    }
}
Web API với Actix-web
use actix_web::{web, App, HttpServer, HttpResponse};
use serde::{Serialize, Deserialize};

#[derive(Serialize, Deserialize)]
struct User { id: u32, name: String }

async fn get_users() -> HttpResponse {
    let users = vec![
        User { id: 1, name: "Minh".into() },
    ];
    HttpResponse::Ok().json(users)
}

#[actix_web::main]
async fn main() -> std::io::Result<()> {
    HttpServer::new(|| {
        App::new()
            .route("/api/users", web::get().to(get_users))
    })
    .bind("0.0.0.0:8080")?
    .run()
    .await
}
Framework phổ biến: Actix-web (nhanh nhất), Axum (Tokio team, ergonomic nhất), Rocket (dễ dùng nhất).

5. TypeScript (Node.js) — Full-Stack JavaScript

Anders Hejlsberg (tạo C#) cũng tạo TypeScript. Cùng cha nên syntax rất giống C#.

⚡ TypeScript 80/20 — Cốt Lõi Cần Nắm

Types, Interfaces, Classes
// Interface — giống hệt C#
interface User {
    id: number;
    name: string;
    email: string;
    isActive: boolean;
    role?: string;         // ? = optional (giống nullable)
}

// Type alias — flexible hơn interface
type UserRole = "admin" | "user" | "moderator";  // Union type
type ApiResponse<T> = {
    data: T;
    message: string;
    success: boolean;
};

// Generics — giống C#
function getFirst<T>(items: T[]): T | undefined {
    return items[0];
}

// Async/Await — giống hệt C#
async function fetchUser(id: number): Promise<User> {
    const res = await fetch(`/api/users/${id}`);
    return res.json();
}
vs C#: Interface syntax gần giống. Generics giống. async/await giống. Khác: Promise<T> = Task<T>. Union types (string | number) C# không có.
Express.js API (phổ biến nhất)
import express from 'express';

const app = express();
app.use(express.json());

// GET /api/users

        [name, email]

    res.status(201).json(user);

app.listen(3000, () => console.log('Server running on :3000'));

6. Python (FastAPI) — AI/ML Backend & Rapid Prototyping

Ngôn ngữ #1 cho AI/ML. FastAPI biến Python thành API backend cực nhanh với auto docs.

⚡ Python 80/20 — Cốt Lõi Cần Nắm

Variables, Types, Classes
# Python dùng indentation thay { } (quan trọng!)
name: str = "Minh"
age: int = 25
is_active: bool = True
scores: list[int] = [90, 85, 95]

# Dataclass = struct/record (C# record)
from dataclasses import dataclass

@dataclass
class User:
    id: int
    name: str
    email: str
    is_active: bool = True  # default value

# Class với methods
class UserService:
    def __init__(self, repo: UserRepository):
        self.repo = repo  # DI qua constructor (giống C#)

    async def get_user(self, id: int) -> User | None:
        return await self.repo.find_by_id(id)

# List comprehension — rất Pythonic
active_names = [u.name for u in users if u.is_active]
# C#: users.Where(u => u.IsActive).Select(u => u.Name)
FastAPI — Modern Python API (auto docs!)
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

# Pydantic model = DTO (auto validation!)
class UserCreate(BaseModel):
    name: str
    email: str

class UserResponse(BaseModel):
    id: int
    name: str
    email: str
    is_active: bool

@app.get("/api/users/{user_id}", response_model=UserResponse)
async def get_user(user_id: int):
    user = await db.find_user(user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    return user

@app.post("/api/users", response_model=UserResponse, status_code=201)
async def create_user(user: UserCreate):
    return await db.create_user(user)

🎯 Chiến Lược Học — Cho Người Đã Biết 1 Ngôn Ngữ

01

Đừng đọc sách từ chapter 1

Bạn đã biết variables, loops, functions. Nhảy thẳng đến phần KHÁC BIỆT: Go → goroutines, error handling. Rust → ownership, borrowing. Python → list comprehension, decorators.

02

Build 1 project nhỏ NGAY

Đọc tutorial 3 ngày < build TODO API trong 3 giờ. Project gợi ý: REST API CRUD + database + authentication. Cùng bài toán, ngôn ngữ khác → thấy khác biệt rõ nhất.

03

So sánh với C# liên tục

"Cái này trong C# là gì?" → xây mental model nhanh hơn 10x. Interface Go = implicit. Error Go = return value. Ownership Rust = tự quản lý memory.

04

Học idioms, không chỉ syntax

Viết Go theo style C# = Go tệ. Mỗi ngôn ngữ có "cách viết đúng". Go: error handling explicit. Rust: ownership + pattern matching. Python: list comprehension + generators.

05

Thứ tự học gợi ý cho bạn

TypeScript (gần C# nhất, 1-2 tuần) → Go (khác biệt vừa, 2-3 tuần) → Python (dễ, cần cho AI, 1 tuần) → Rust (khó, dành thời gian, 1-2 tháng).

06

Không cần master — cần "đủ dùng"

80/20 = nắm 20% syntax + ecosystem + best practices = giải quyết 80% công việc. Chuyên sâu C#/.NET + biết đủ 2-3 ngôn ngữ khác = profile Team Lead mạnh.

🔄 7 Bước Tiếp Cận Ngôn Ngữ Mới — The Universal Flow

Không cần thay đổi. Áp dụng bất kỳ ngôn ngữ nào, bất kỳ lúc nào. Mỗi bước ~1-3 ngày cho người đã biết 1 ngôn ngữ.

1

WHY — Tại sao ngôn ngữ này tồn tại?

⏱ 2 giờ

Mỗi ngôn ngữ được tạo ra để giải quyết 1 vấn đề cụ thể mà ngôn ngữ cũ chưa làm tốt. Hiểu "why" = hiểu mọi design decision sau này.

Đọc trang "About" trên official site Tìm bài "Why [Language] was created" Xem creator nói về motivation
Ví dụ: Go = Google cần build microservices nhanh, compile nhanh, concurrency dễ → hiểu tại sao Go đơn giản, không có generics (lúc đầu), goroutines là core.
Rust = Mozilla cần browser engine an toàn + nhanh → hiểu tại sao ownership system tồn tại.
2

SETUP — Cài đặt + Hello World + Build tool

⏱ 1-2 giờ

Cài xong, chạy được Hello World = bạn đã vượt qua 50% rào cản tâm lý. Đừng đọc thêm — hãy chạy code trước.

Cài SDK/Runtime Setup IDE + extensions Hello World chạy được Hiểu build tool (cargo, go build, npm...)
Checklist: go mod init / cargo new / npm init → tạo project → build → run → thấy output. Done. Không cần hiểu gì thêm ở bước này.
3

MAP — Syntax mapping từ ngôn ngữ cũ

⏱ 3-4 giờ

Đây là bước quan trọng nhất. Không học syntax mới — mà MAP syntax cũ sang syntax mới. Bạn đã biết concepts, chỉ cần biết "viết khác như nào".

Variable: var/let/const → ? Function: cách khai báo → ? Class/Struct: → ? Interface: → ? Error handling: try/catch → ? Null handling: → ? Collection: List, Dict → ? Async: async/await → ?
Cách làm: Mở 2 tab — C# code bên trái, ngôn ngữ mới bên phải. Viết lại CÙNG 1 đoạn code. Ghi chú khác biệt. Sau 3-4 giờ bạn sẽ "à, hiểu rồi".
4

UNIQUE — Học cái ĐẶC BIỆT chỉ ngôn ngữ này có

⏱ 1-2 ngày

Mỗi ngôn ngữ có 2-3 concepts KHÔNG tồn tại trong ngôn ngữ khác. Đây mới là thứ cần dành thời gian. Phần còn lại chỉ là syntax khác.

Tìm "What makes [Lang] unique" Đọc sâu 2-3 concepts đặc biệt Viết code thử nghiệm
Go: Goroutines + Channels, implicit interfaces, multiple return values, defer
Rust: Ownership + Borrowing, lifetime, pattern matching, Result/Option bắt buộc
TypeScript: Union types, type narrowing, mapped types, conditional types
Python: List comprehension, decorators, generators, GIL, dunder methods
Kotlin: Coroutines, sealed classes, extension functions, null safety built-in
5

BUILD — Xây CRUD API (cùng bài toán, ngôn ngữ mới)

⏱ 1-2 ngày

Luôn build cùng 1 project cho mọi ngôn ngữ. REST API CRUD + database + validation. Cùng bài toán → thấy khác biệt rõ nhất. Đây là lúc kiến thức "click".
