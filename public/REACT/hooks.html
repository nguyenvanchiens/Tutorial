React Hooks

Hooks là cách "inject" state & side effect vào function component. Nắm vững 8 hooks cốt lõi, bạn viết được 99% app React.

Quy tắc vàng của Hooks

1. Chỉ gọi ở top-level

Không gọi hook trong if, for, sau return, hay function lồng. React dựa vào thứ tự gọi hook để map state — đổi thứ tự = loạn state.

// SAI
if (condition) {
  const [x, setX] = useState(0);
}

// ĐÚNG
const [x, setX] = useState(0);
if (condition) { /* dùng x */ }

2. Chỉ gọi trong Component hoặc Custom Hook

Không gọi hooks trong function thường, class, hay event handler. Custom hook phải bắt đầu bằng use để ESLint nhận biết.

Cài ESLint plugin: eslint-plugin-react-hooks tự bắt vi phạm. Đừng bao giờ disable nó.

1. useState — State cục bộ

Đã học ở trang Cơ bản. Ở đây đi sâu các pattern ít người biết.

// ❌ Khởi tạo nặng chạy MỖI LẦN render
const [data, setData] = useState(computeExpensive());

// ✅ Lazy initial — chỉ chạy 1 lần
const [data, setData] = useState(() => computeExpensive());

// ✅ Batching: React 18+ gộp nhiều setState trong cùng tick
function handle() {
  setA(1);
  setB(2);  // chỉ 1 lần render cho cả 2
  setC(3);
}

// ✅ State reset bằng key (pattern hay gặp)
<Form key={userId} />  // đổi userId → Form remount, state reset

2. useEffect — Side Effect

Side effect = mọi thứ không phải tính toán thuần: fetch API, subscribe, timer, thao tác DOM, log analytics.

3 dạng deps array

// Không truyền — chạy MỖI render
useEffect(() => {
  console.log('every render');
});

// Array rỗng — chạy 1 lần (mount)
useEffect(() => {
  console.log('mount only');
}, []);

// Có deps — chạy khi deps đổi
useEffect(() => {
  fetchUser(id);
}, [id]);

Cleanup

useEffect(() => {
  const timer = setInterval(tick, 1000);

  // cleanup chạy khi:
  // - deps đổi (trước lần chạy kế)
  // - component unmount
  return () => clearInterval(timer);
}, []);
Luôn cleanup: timer, subscribe, WebSocket, event listener, AbortController. Không cleanup = memory leak + bug race condition.

Fetch data đúng cách (chống race condition)

useEffect(() => {
  const ctrl = new AbortController();

  fetch(`/api/user/${id}`, { signal: ctrl.signal })
    .then(r => r.json())
    .then(setUser)
    .catch(err => {
      if (err.name !== 'AbortError') setError(err);
    });

  return () => ctrl.abort();
}, [id]);
Tại sao? User đổi id nhanh: request 1 có thể về SAU request 2 → set state sai. AbortController huỷ request cũ khi deps đổi.

Khi nào KHÔNG cần useEffect?

❌ Tính toán derived state

// SAI — dùng effect để sync state phụ thuộc
const [list, setList] = useState([]);
const [filtered, setFiltered] = useState([]);
useEffect(() => {
  setFiltered(list.filter(x => x.active));
}, [list]);

// ĐÚNG — tính trực tiếp trong render
const filtered = list.filter(x => x.active);

❌ Phản ứng với event

// SAI
useEffect(() => {
  if (submitted) sendAnalytics();
}, [submitted]);

// ĐÚNG — đặt vào chính event handler
const handleSubmit = () => {
  setSubmitted(true);
  sendAnalytics();
};

3. useRef — Giữ giá trị không trigger render

2 công dụng chính: (1) tham chiếu tới DOM element, (2) giữ giá trị mutable xuyên các lần render mà không re-render.

Tham chiếu DOM

function AutoFocus() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus();
  }, []);

  return <input ref={inputRef} />;
}

Giữ giá trị mutable

function Timer() {
  const intervalRef = useRef(null);

  const start = () => {
    intervalRef.current = setInterval(tick, 1000);
  };
  const stop = () => {
    clearInterval(intervalRef.current);
  };
  // intervalRef tồn tại qua nhiều render
  // mà KHÔNG làm component re-render khi gán
}
Quy tắc: đừng đọc/ghi ref.current trong render (lifecycle chưa chắc ổn). Làm trong event handler hoặc useEffect.

4. useMemo & useCallback — Memoization

useMemo — cache giá trị

const sorted = useMemo(() => {
  return items.slice().sort(compareFn);
}, [items]);
// Chỉ tính lại khi items đổi

useCallback — cache function

const handleDel = useCallback((id) => {
  setItems(prev => prev.filter(x => x.id !== id));
}, []);
// Tương đương useMemo(() => fn, deps)
KHÔNG dùng để "tối ưu cho chắc". Memoization bản thân tốn RAM + CPU so sánh deps. Chỉ dùng khi:
  • Tính toán thực sự nặng (sort list 10k+, parse…)
  • Truyền prop xuống component đã React.memo
  • Dùng làm dep cho useEffect và cần stable reference

5. useContext — Chia sẻ state xuyên cây

Giải quyết prop drilling: khi prop phải xuyên qua nhiều tầng chỉ để đến component sâu.

// 1. Tạo context
const ThemeContext = createContext('light');

// 2. Cung cấp giá trị
function App() {
  const [theme, setTheme] = useState('dark');
  return (
    <ThemeContext.Provider value={{ theme, setTheme }}>
      <Page />
    </ThemeContext.Provider>
  );
}

// 3. Đọc ở component sâu
function Button() {
  const { theme } = useContext(ThemeContext);
  return <button className={theme}>Click</button>;
}
Bẫy hiệu năng: mọi consumer của Context re-render khi value đổi. Nếu truyền object mới mỗi render → toàn cây re-render. Giải pháp: useMemo cho value, hoặc tách Context ra theo từng mối quan tâm.

6. useReducer — State phức tạp

Khi state có nhiều field liên quan, nhiều cách update — reducer sạch hơn nhiều useState.

function reducer(state, action) {
  switch (action.type) {
    case 'add':    return { ...state, list: [...state.list, action.item] };
    case 'remove': return { ...state, list: state.list.filter(x => x.id !== action.id) };
    case 'clear':  return { ...state, list: [] };
    default: throw new Error('Unknown: ' + action.type);
  }
}

function Cart() {
  const [state, dispatch] = useReducer(reducer, { list: [] });

  return <button onClick={() => dispatch({ type: 'add', item })}>+</button>;
}
Khi nào dùng reducer? >3 useState liên quan, logic update chạy trùng lặp, hoặc cần test reducer riêng. Reducer là pure function → test dễ.

7. Các hook khác cần biết

useId

Sinh id duy nhất, cùng ID ở SSR & client. Dùng cho htmlFor, aria-describedby.

const id = useId();
<label htmlFor={id}>Email</label>
<input id={id} />

useLayoutEffect

Giống useEffect nhưng chạy đồng bộ sau DOM mutation, trước browser paint. Dùng khi cần đo kích thước DOM để tránh flash.

useSyncExternalStore

Subscribe vào external store (redux-like) an toàn với concurrent rendering. Dùng khi viết state library.

useDeferredValue (React 18+)

Deferred render phần nặng, giữ input mượt. Dùng cho tìm kiếm instant.

const deferred = useDeferredValue(query);
<Results query={deferred} />

useTransition (React 18+)

Đánh dấu update là "không khẩn cấp" để React ưu tiên input.

const [pending, startTransition] = useTransition();
startTransition(() => setTab('slow'));

useOptimistic (React 19)

Hiển thị state "lạc quan" trước khi server xác nhận. Tuyệt cho form mutation.

8. Custom Hooks — Tái sử dụng logic

Custom hook = function gọi hooks khác, bắt đầu bằng use. Giúp tách logic khỏi component.

useLocalStorage

function useLocalStorage(key, initial) {
  const [value, setValue] = useState(() => {
    const raw = localStorage.getItem(key);
    return raw ? JSON.parse(raw) : initial;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

// Dùng
const [theme, setTheme] = useLocalStorage('theme', 'dark');

useDebounce

function useDebounce(value, delay = 500) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);

  return debounced;
}

// Dùng
const debouncedQuery = useDebounce(query, 300);
useEffect(() => { fetchResults(debouncedQuery); }, [debouncedQuery]);

useFetch

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const ctrl = new AbortController();
    setLoading(true);

    fetch(url, { signal: ctrl.signal })
      .then(r => r.json())
      .then(setData)
      .catch(e => e.name !== 'AbortError' && setError(e))
      .finally(() => setLoading(false));

    return () => ctrl.abort();
  }, [url]);

  return { data, loading, error };
}

usePrevious

function usePrevious(value) {
  const ref = useRef();
  useEffect(() => { ref.current = value; }, [value]);
  return ref.current;
}

// Dùng
const prev = usePrevious(count);
<p>Trước: {prev}, giờ: {count}</p>

useMediaQuery

function useMediaQuery(query) {
  const [matches, setMatches] = useState(
    () => window.matchMedia(query).matches
  );

  useEffect(() => {
    const mq = window.matchMedia(query);
    const h = (e) => setMatches(e.matches);
    mq.addEventListener('change', h);
    return () => mq.removeEventListener('change', h);
  }, [query]);

  return matches;
}

useOnClickOutside

function useOnClickOutside(ref, handler) {
  useEffect(() => {
    const listener = (e) => {
      if (ref.current && !ref.current.contains(e.target)) {
        handler(e);
      }
    };
    document.addEventListener('mousedown', listener);
    return () => document.removeEventListener('mousedown', listener);
  }, [ref, handler]);
}
Quy tắc đặt custom hook: chỉ tách thành hook khi logic thực sự được tái dùng nhiều nơi hoặc khi component quá dài. Đừng over-abstract.

💡 Bài tập

  1. Viết useToggle — trả về [value, toggle]. Thử nghiệm Dark mode switch.
  2. Search với debounce — input → fetch /api/search?q= sau 300ms dừng gõ. Kèm AbortController.
  3. Reducer cho TodoApp — viết reducer xử lý: add, toggle, delete, clearDone, setFilter.
  4. Theme Context — 1 Provider quản light/dark, useTheme() hook để đổi. Nhớ memo value.
  5. Infinite scroll — custom hook useInfiniteScroll dùng IntersectionObserver, load thêm khi cuộn tới cuối.
