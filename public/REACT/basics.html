React Cơ Bản

JSX, Component, Props, State, Events, Conditional rendering, Lists & Keys, Forms. Đây là 8 khối xây nên mọi ứng dụng React.

1. Setup dự án React

Vite là công cụ chuẩn 2026 — nhanh, HMR tức thì, config tối thiểu. Create React App đã ngừng phát triển.

# Tạo project mới
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

# Cấu trúc tối thiểu
src/
  main.jsx      // điểm vào, gắn App vào #root
  App.jsx       // component gốc
  components/   // các component con
  hooks/        // custom hooks
index.html      // chứa <div id="root"></div>
Mẹo: Thêm eslint-plugin-react-hooks ngay từ đầu. Nó bắt 90% lỗi về dependency array và rules of hooks.

2. JSX — HTML trong JavaScript

JSX chỉ là cú pháp thân thiện, sau khi compile nó biến thành React.createElement(...). Nhớ: đang viết JS, không phải HTML.

Cú pháp cơ bản

const name = "Chiến";

const element = (
  <div className="box">
    <h1>Xin chào {name}</h1>
    <p>2 + 2 = {2 + 2}</p>
  </div>
);

Khác biệt với HTML

HTMLJSX
classclassName
forhtmlFor
onclickonClick
inline style="..."style={{color: 'red'}}
<input><input /> (self-close)

Quy tắc vàng của JSX

  • Một root element: dùng <>...</> (Fragment) nếu không muốn thêm div thừa.
  • Mọi biến JS trong { }: kể cả hàm, array, ternary. Nhưng không được if/for statement.
  • Attribute dùng camelCase: tabIndex, readOnly, autoFocus.
  • Comment trong JSX: {/* comment */}, không dùng <!-- -->.

3. Component — Khối Lego của React

Component là function JavaScript trả về JSX. Tên component phải viết hoa chữ cái đầu (React phân biệt <Button> là component vs <button> là HTML tag).

// components/Greeting.jsx
export default function Greeting() {
  return <h1>Hello React</h1>;
}

// App.jsx
import Greeting from './components/Greeting';

export default function App() {
  return (
    <div>
      <Greeting />
      <Greeting />  // tái sử dụng vô hạn
    </div>
  );
}
Quy tắc đặt tên file: PascalCase cho component (UserCard.jsx), camelCase cho hook/util (useFetch.js, formatDate.js).

4. Props — Truyền dữ liệu xuống con

Props giống tham số hàm. Con chỉ đọc props, không được sửa (immutable).

Truyền & nhận props

// Con
function UserCard({ name, age, avatar }) {
  return (
    <div className="card">
      <img src={avatar} />
      <h3>{name}</h3>
      <p>{age} tuổi</p>
    </div>
  );
}

// Cha
<UserCard
  name="Chiến"
  age={25}
  avatar="/me.jpg"
/>

Default + Rest

function Button({
  variant = 'primary',  // default
  size = 'md',
  children,            // nội dung bên trong
  ...rest              // các prop còn lại
}) {
  return (
    <button
      className={`btn ${variant} ${size}`}
      {...rest}>
      {children}
    </button>
  );
}

// Dùng
<Button variant="danger" onClick={handleDel}>
  Xoá
</Button>

children — prop đặc biệt

function Card({ title, children }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <div>{children}</div>
    </div>
  );
}

<Card title="Thông báo">
  <p>Nội dung tuỳ ý ở đây</p>
  <button>OK</button>
</Card>
Không làm điều này: props.name = 'new' — React không theo dõi, và sẽ gây bug khó tìm. Muốn "đổi" → tạo state mới hoặc gọi callback.

5. State với useState

State là dữ liệu thay đổi theo thời gian và cần React render lại khi thay đổi.

Cú pháp cơ bản

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Đã bấm {count} lần</p>
      <button onClick={() => setCount(count + 1)}>
        +1
      </button>
    </div>
  );
}

Functional update (an toàn)

// Khi state mới phụ thuộc state cũ
// → TRUYỀN FUNCTION, không truyền giá trị

const handleClick = () => {
  setCount(c => c + 1);
  setCount(c => c + 1);
  setCount(c => c + 1);
  // count tăng 3, không phải 1
};

// Nếu viết setCount(count+1) 3 lần
// → cả 3 đều dùng count cũ → chỉ +1

Những kiểu state hay dùng

// Object state — nhớ spread khi cập nhật
const [user, setUser] = useState({ name: '', age: 0 });
setUser({ ...user, name: 'Chiến' });

// Array state — không mutate, tạo array mới
const [todos, setTodos] = useState([]);
setTodos([...todos, newTodo]);               // thêm
setTodos(todos.filter(t => t.id !== id));     // xoá
setTodos(todos.map(t => t.id === id ? {...t, done: true} : t));  // sửa

// Lazy initial — tính toán nặng chỉ chạy 1 lần
const [items, setItems] = useState(() => {
  return JSON.parse(localStorage.getItem('items')) ?? [];
});
Nguyên tắc: State là snapshot. Trong 1 lần render, biến count là hằng số. Gọi setCount chỉ lên lịch render mới, KHÔNG đổi biến hiện tại.

6. Xử lý Events

function Form() {
  const handleSubmit = (e) => {
    e.preventDefault();  // chặn reload trang
    console.log('submitted');
  };

  const handleChange = (e) => {
    console.log(e.target.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input onChange={handleChange} />
      <button onClick={(e) => e.stopPropagation()}>OK</button>
    </form>
  );
}
Synthetic Event: React bọc native event thành SyntheticEvent để cross-browser. API gần như y hệt (e.target, e.preventDefault(), …).

7. Conditional Rendering

Ternary — phổ biến nhất

{isLoggedIn
  ? <Dashboard />
  : <Login />}

Short-circuit với &&

{cart.length > 0 && (
  <CartBadge count={cart.length} />
)}
Bẫy: {count && <X/>} khi count=0 sẽ render ra "0". Dùng {count > 0 && ...}.

Early return

function Profile({ user }) {
  if (!user) return <Spinner />;
  if (user.banned) return <Banned />;

  return <UserCard user={user} />;
}

Map cho nhiều trường hợp

const STATUS = {
  loading: <Spinner />,
  error:   <ErrorView />,
  success: <DataView />,
};
return STATUS[status];

8. Lists & Keys

const users = [
  { id: 1, name: 'Chiến' },
  { id: 2, name: 'Lan' },
];

return (
  <ul>
    {users.map(u => (
      <li key={u.id}>{u.name}</li>
    ))}
  </ul>
);

✅ Key tốt

  • Giá trị ổn định, duy nhất trong phạm vi list
  • Thường là id từ DB, uuid
  • Tuyệt đối không đổi giữa các lần render

❌ Key tệ

  • index khi list thay đổi thứ tự/insert/remove
  • Math.random() — đổi mỗi render → mọi item bị remount, mất state/focus
  • Trùng lặp — React warning & dính bug

9. Forms — Controlled Inputs

React pattern chuẩn: form field được điều khiển bởi state. Single source of truth.

function LoginForm() {
  const [form, setForm] = useState({ email: '', password: '' });

  const onChange = (e) => {
    const { name, value } = e.target;
    setForm(f => ({ ...f, [name]: value }));
  };

  const onSubmit = (e) => {
    e.preventDefault();
    console.log(form);
  };

  return (
    <form onSubmit={onSubmit}>
      <input
        name="email"
        value={form.email}
        onChange={onChange}
      />
      <input
        name="password"
        type="password"
        value={form.password}
        onChange={onChange}
      />
      <button>Đăng nhập</button>
    </form>
  );
}
Khi form phức tạp (validate, nhiều step, arrays): dùng react-hook-form + zod — xem trang Ecosystem.

10. Styling — 4 cách phổ biến

1. CSS file + className

// Button.css
.btn { padding: 8px 16px; }

// Button.jsx
import './Button.css';
<button className="btn">OK</button>

2. CSS Module — scoped

// Button.module.css
.btn { color: blue; }

// Button.jsx
import s from './Button.module.css';
<button className={s.btn}>OK</button>

3. Tailwind CSS (utility-first)

<button className="px-4 py-2 bg-blue-500
  text-white rounded hover:bg-blue-600">
  OK
</button>

Nhanh, đồng nhất, tree-shake tự động. Chuẩn 2026.

4. CSS-in-JS

// styled-components / emotion
const Btn = styled.button`
  padding: 8px 16px;
  background: ${p => p.primary ? 'blue' : 'gray'};
`;

Mạnh nhưng chi phí runtime. 2026 ít dùng hơn Tailwind.
